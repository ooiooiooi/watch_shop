# Frontend Design

Build distinctive, production-grade frontend interfaces with a clear visual point of view.

## When To Invoke

Invoke this skill when:

- user asks to build or optimize frontend pages/components
- user wants higher visual quality for dashboard, website, app, or admin UI
- user asks for styling/beautification, interaction polish, motion, or layout refinement

## Core Principles

1. Pick an explicit design direction before coding.
2. Keep the visual system consistent: typography, color, spacing, radius, borders, shadows.
3. Build real, functional code first; then polish interaction and aesthetics.
4. Avoid generic "AI template" visuals; make the UI memorable and intentional.

## Design Workflow

1. Clarify context
- audience, purpose, usage frequency, key workflows

2. Commit to a style direction
- examples: luxury/editorial, brutalist, playful, minimal, retro-futuristic
- define color, typography, motion, and composition choices

3. Implement a cohesive system
- use design tokens (CSS variables) for colors, spacing, radius, shadows
- keep components reusable and consistent

4. Polish interaction
- hover/focus/active states
- transitions and micro-interactions
- clear visual hierarchy and affordances

5. Validate
- responsive behavior
- readability/contrast
- accessibility and keyboard basics

## Practical Guidance

- Typography
  - Pair a characterful heading font with a readable UI/body font.
  - Use clear hierarchy and avoid overly uniform text styles.

- Color
  - Favor a strong dominant palette with selective accents.
  - Keep semantic colors for success/warning/error actions.

- Layout
  - Use intentional spacing rhythm and density.
  - Cards, panels, and sections should feel structurally coherent.

- Motion
  - Prefer subtle transitions; emphasize key moments over constant animation.

- Components
  - Buttons: clear primary/secondary/destructive hierarchy.
  - Tables/forms/modals: consistent borders, focus states, and spacing.

## Output Expectations

- Production-ready code
- Distinct, coherent visual style
- Functional and maintainable implementation
